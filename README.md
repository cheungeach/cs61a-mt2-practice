# CS61A Midterm 2 Practice

A single-file practice page for the CS61A (UC Berkeley) Midterm 2 topics. Pick a problem, write Python, and run the tests. Your code runs in your browser (via Skulpt), so there is nothing to install.

## How to use

1. Download `CS61A Midterm 2 Practice.html` (click the file, then the download icon), or clone this repo.
2. Open the file in Chrome, Edge, or Safari.
3. Pick a problem on the left, write your solution on the right, and click Run to see the test results.

Your progress is saved in your own browser.

The first time you open it you need an internet connection, because the Python interpreter (Skulpt) and fonts load from the web. After that your browser will usually have them cached.
