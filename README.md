# CS61A Midterm 2 Practice

A single-file practice site for the CS61A (UC Berkeley) Midterm 2 topics. Open it in a browser and work through the problems. Python code runs locally in your browser (via Skulpt), so no install and no server are needed.

## Use it

1. Download `CS61A-MT2-Practice.html` (or clone this repo).
2. Open the file in any modern browser.
3. Pick a problem on the left, write your solution, and run the tests.

Progress is saved in your browser's localStorage.

## Optional: "Ask Claude"

The page has an optional "Ask Claude" box. It only works if you paste your own Anthropic API key. The key stays in your browser's localStorage and is sent only to api.anthropic.com. No key is included in this repo. Everything else works fully offline.
